Um jogo 2D de exploração de masmorras e combate cooperativo, desenvolvido com HTML, CSS e JavaScript.
Dungeonfall foi desenvolvido durante um **hackathon escolar**, com autorização do professor para utilizar inteligência artificial como ferramenta de apoio à programação e ao desenvolvimento do jogo.
A IA auxiliou na implementação e no aprimoramento de funcionalidades durante o processo de criação.
